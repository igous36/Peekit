# 插画预览应用 · 设计交接包

> 这是最初交接包的说明，原本放在项目根目录的 README.md。6 个阶段已经全部完成（2026-11-17），应用后来改名为 Peekit；项目说明见根目录的 [README.md](../README.md)。下面表格里的文件都在项目根目录。

这个文件夹是从 Claude Design 交给 Claude Code 的全部材料。

| 文件 | 内容 |
|---|---|
| `HANDOFF.md` | 完整开发规范：布局、设计变量、组件、交互、动效、关键算法、边界情况、无障碍 |
| `CLAUDE.md` | 给 Claude Code 的项目说明：技术选型、渲染架构、性能要求 |
| `design/prototype.dc.html` | 可交互原型的源码（动画数学的唯一来源） |
| `design/spec-motion.dc.html` | 规范画板 01 · 交互与动效 |
| `design/spec-visual.dc.html` | 规范画板 02 · 视觉 |
| `screenshots/` | 默认状态、拖动中（玻璃让开）、停下后（玻璃合拢）、系列视图 |

## 怎么用

1. 解压到一个新的空文件夹，比如 `illustration-preview/`。
2. 在这个文件夹里打开终端，运行 `claude` 启动 Claude Code。
3. 把下面这段话粘贴给它。

```
这个文件夹是一个桌面插画预览应用的设计交接包。请先读 README.md、CLAUDE.md 和 HANDOFF.md，
再看 design/prototype.dc.html 里的逻辑代码，然后用 Tauri 2 + Vite + 原生 TypeScript 实现它。

请分阶段做，每做完一个阶段就停下来，让我运行看效果：
1. 搭好 Tauri 项目和无边框窗口，用原型里的 12 幅示例数据（色块占位图）把静态布局摆出来：
   磨砂玻璃网格、三幅画作、信息卡、时间轴。
2. 动画引擎：弹簧、横向拖动、惯性吸附、画作沉入玻璃、玻璃避让和合拢。
   手感要和原型完全一致，参数照抄 HANDOFF.md 第 6、7 节。
3. 纵向拖动拉远镜头，同系列作品浮现；键盘和触控板操作。
4. 系列标签编辑，并保存到本地。
5. 导入真实插画：选择文件夹、生成缩略图、读取日期。开始这一步之前，先问我数据方面的几个问题
   （CLAUDE.md 的“数据”一节）。
6. 性能检查（拖动时保持 60fps，静止时不空转）和打包。

如果规范里有没写清楚的地方，先问我，不要自己猜。
```
